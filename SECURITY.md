# Security

These skills are instructions and scripts that AI agents follow on your computer. A harmful instruction or script in
them is a security problem, even if it looks like a normal change.

## Report a problem privately

Use GitHub's private reporting: the **Security** tab of this repo, then **Report a vulnerability**. Please do not open
a public issue for it. I will reply as soon as I can, fix it, and credit you if you want.

## Before you install or update

Read the `SKILL.md` files and scripts you install, as you would any code you run. Pull requests are reviewed by hand
before they are merged.
